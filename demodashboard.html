ℹ️ CRF & Encoder Settings for H.264 vs H.265 Guideline

1. Video Codec Introduction: H.264 vs H.265

H.264 (AVC) — Legacy & Reliable: Widely compatible with almost all devices, phones, and old TVs, but yields relatively larger file sizes.

H.265 (HEVC) — Modern & Super-Efficient: Cuts file sizes down by roughly half (~50% smaller) while maintaining comparable visual quality.

2. What is CRF? (Quality Control Made Simple)

CRF (Constant Rate Factor) targets visual quality: lower numbers give better quality/larger files, while higher numbers reduce file sizes.

ℹ️ What is a Suffix?

A suffix is a short text label automatically added to the end of your processed or compressed file's name (placed right before the file format extension).

Original File: video.mov
With Suffix (_compressed): video_compressed.mp4

Why use it? It helps you easily distinguish your compressed files from the original sources, avoiding confusion or accidental overwriting. You can choose a preset style (_compressed, _com, etc.), set it to blank (keeps the original name), or type a custom text.

ℹ️ What is Scan Interval?

The Scan Interval defines how frequently (in seconds) the Watchdog Encoder scans your watch folder to detect newly added video or asset files.

Default Setting: 30 seconds
Behavior: Checks the watch directory at the set frequency to automatically capture and enqueue new files.

Tips for tuning:

  • Shorter intervals (5s – 10s): Detects newly dropped files almost instantly, but increases background directory checks.
  • Longer intervals (60s – 120s): Minimizes system overhead, but introduces a slight delay before newly added files are picked up.

ℹ️ What is Max Failed Retries?

Max Failed Retries defines the maximum number of times the encoder will automatically retry processing a file if its initial encode or copy task fails.

Default Setting: 3 to 5 attempts
Behavior: If an error occurs (e.g., temporary file lock or system glitch), the script retries instead of marking it permanently failed right away.

Why is it important? It ensures robust automation. Temporary network or drive issues won't halt your entire workflow, as the encoder will give the file a few more chances to process successfully.

ℹ️ What is Max Stabilize Attempts?

Max Stabilize Attempts defines how many times the encoder checks a source file to verify that its file size has stopped growing (meaning it has finished copying or downloading completely) before starting compression.

Default Setting: 5 to 7 attempts
Behavior: Measures file size periodically. Once the size remains unchanged for consecutive checks, encoding begins.

Why is it important? This prevents the encoder from starting on a video file while it is still actively being copied or written to the watch folder, avoiding corrupted outputs or incomplete reads.
