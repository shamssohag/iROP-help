ℹ️ Complete Guide: Video Codecs & CRF Quality Control

1. Understanding Video Codecs (H.264 vs H.265)

Choosing the right codec determines your compatibility vs storage balance:

H.264 (AVC) — Legacy & Universal

The industry standard for over a decade. Plays smoothly on 100% of old and new devices, but file sizes are significantly larger.

H.265 (HEVC) — Modern Super-Compressor

The next-generation standard. Delivers identical visual quality to H.264 while cutting file sizes down by roughly 50%. Ideal for massive archives.

2. What is CRF (Constant Rate Factor)?

CRF is your main dial for targeting video quality. Instead of fixing a strict bitrate, CRF tells the encoder to maintain a consistent quality level throughout the video.

  • Lower CRF Number (e.g., 18-22): Better visual quality, larger file sizes (Best for master copies and editing).
  • Higher CRF Number (e.g., 28-32): Smaller file sizes, slight quality reduction (Best for web sharing and long-term storage).
  • Default Recommendation: CRF 28 is the sweet spot for H.265 archiving, giving great clarity with massive space savings.

3. Recommended Settings Combination Chart

Goal / Use Case Codec CRF Range Expected Outcome
Master Archiving libx265 23 - 25 Visually lossless, optimal long-term backup.
Standard Production (Default) libx265 28 Perfect balance of crisp quality and small size.
Maximum Storage Saving libx265 32 - 35 Aggressive compression for low-priority raw footage.

ℹ️ Complete Guide: File Suffixing

A Suffix is a text marker automatically added to the end of your processed file name, right before the extension (e.g., .mp4).

Example Naming Transformation:
Original Source: Interview_RAW.mov
With Suffix (_compressed): Interview_RAW_compressed.mp4
Why is this essential?
  • Prevents the encoder from accidentally overwriting your precious original files.
  • Makes it instantly recognizable in your output folders which files have been optimized.
  • Options include presets like _compressed, _com, leaving it blank, or writing a custom text.

ℹ️ Complete Guide: Scan Interval & Polling

The Scan Interval dictates how often (measured in seconds) the watchdog engine wakes up to inspect your watch directories for newly dropped files.

Tuning Recommendations:
  • Fast Scan (5s - 10s): Great for immediate turnaround, but causes heavier background drive scanning overhead.
  • Balanced Standard (30s — Default): The optimal choice for standard studio workflows, conserving system resources.
  • Relaxed Scan (60s - 120s): Best for massive network drives where frequent polling might cause network clutter.

ℹ️ Complete Guide: Max Failed Retries

Max Failed Retries sets the error tolerance limit. If a file fails to compress or copy due to a temporary glitch (e.g., file lock, network blip, external drive disconnect), the script will automatically retry processing it up to this specified count.

Why this matters:

Instead of immediately marking a file as permanently failed and halting your unattended overnight batch job, the encoder gives it multiple intelligent recovery chances, ensuring robust, hands-free automation.

ℹ️ Complete Guide: Max Stabilize Attempts

When large video files are being copied or downloaded into your watch folder, they arrive slowly. Max Stabilize Attempts ensures the encoder waits until the file size completely stops growing before starting compression.

Safety Protection:

This prevents the encoder from grabbing a half-copied file, which would result in corrupted output videos or incomplete reads. Once file size stability is confirmed across consecutive checks, encoding begins safely.

ℹ️ Complete Guide: FFmpeg & FFprobe Setup

FFmpeg is the core multimedia engine driving this encoder. You are free to place the ffmpeg folder anywhere on your system storage (e.g., C drive, D drive, or external storage volumes).

Required Folder Hierarchy:
📁 ffmpeg/
└── 📁 bin/
├── ⚙️ ffmpeg.exe
└── ⚙️ ffprobe.exe

If stored in a non-default location, simply switch to Custom Path in the configuration editor and point directly to the respective executable file inside your bin folder.
