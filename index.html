ℹ️ Complete Guide: Video Codecs & CRF Quality Control

1. Understanding Video Codecs (H.264 vs H.265)

Choosing the right video codec determines the balance between device compatibility and storage efficiency:

H.264 (AVC) — Legacy & Universal

The industry standard for over a decade. It plays on 100% of old and new devices, phones, and TVs, but results in much larger file sizes.

H.265 (HEVC) — Modern Super-Compressor

The modern standard. It delivers identical visual quality to H.264 while cutting file sizes down by roughly 50%. Perfect for long-term archiving.

2. What is CRF (Constant Rate Factor)?

CRF is your primary quality control scale. Instead of locking a fixed bitrate, CRF tells the encoder to target a consistent level of visual fidelity throughout the video.

  • Lower Numbers (e.g., 18–22): Higher visual quality, larger file sizes (Recommended for master edits).
  • Higher Numbers (e.g., 28–35): Smaller file sizes, minor quality reduction (Recommended for storage saving and web sharing).
  • Default Setting (28): The optimal sweet spot for H.265 archiving, giving great clarity with massive space savings.

3. Recommended Settings Combination Chart

Goal / Use Case Codec CRF Range Expected Outcome

Standard Production (Default) libx265 28 The ultimate balance of crisp quality and small size.

ℹ️ Complete Guide: File Suffixing

A Suffix is a custom text marker automatically appended to the end of your compressed file's name, placed right before the file format extension (e.g., .mp4).

Example Naming Transformation:
Original File: Interview_RAW.mov
With Suffix (_compressed): Interview_RAW_compressed.mp4
Why is this essential?
  • Prevents the encoder from accidentally overwriting your original raw source files.
  • Instantly identifies optimized files in your destination folders.
  • You can choose presets like _compressed, _com, set it to blank (keeps original name), or type custom text.

ℹ️ Complete Guide: Scan Interval & Polling

The Scan Interval determines how frequently (in seconds) the Watchdog service polls your watch folder to discover newly dropped video or asset files.

Tuning Recommendations:
  • Short Interval (5s – 10s): Detects new files almost instantly, but increases background drive checking overhead.
  • Standard Interval (30s — Default): The ideal balance for general workflows, conserving system resources.
  • Long Interval (60s – 120s): Best for massive network storage where frequent polling might cause network clutter.

ℹ️ Complete Guide: Max Failed Retries

Max Failed Retries defines the error tolerance limit. If initial file encoding or copying fails due to a temporary glitch (e.g., file lock, network blip, or drive latency), the script will automatically retry processing up to this limit.

Why is this important?

Instead of immediately marking a file as permanently failed during an unattended overnight batch job, it gives the file multiple intelligent recovery chances, ensuring robust, hands-free automation.

ℹ️ Complete Guide: Max Stabilize Attempts

When large video files are actively being copied or downloaded into your watch folder, Max Stabilize Attempts ensures the encoder waits until the file size completely stops growing before starting compression.

Safety Protection:

This prevents the encoder from starting on a video file while it is still actively writing, avoiding corrupted output videos or incomplete reads. Once stability is confirmed across checks, processing begins safely.

ℹ️ Complete Guide: FFmpeg & FFprobe Setup

FFmpeg is the core multimedia processing engine. You can place the ffmpeg folder anywhere on your system storage (e.g., C drive, D drive, or external volumes).

Required Folder Hierarchy:
📁 ffmpeg/
└── 📁 bin/
├── ⚙️ ffmpeg.exe
└── ⚙️ ffprobe.exe

If stored in a custom directory, simply select Custom Path in the configuration editor and point directly to the respective executable file inside your bin folder.
